# Getting started 🛠️

### Prerequisites
Since these projects include graphical components, you just need Python installed on your system.
The `turtle` module comes built-in with standard Python installations.


### Running the Project
To see one of the drawings or programs in action, run the file from your terminal:
```bash
python name_of_file.py
```
